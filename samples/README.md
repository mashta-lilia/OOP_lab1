# Тестові файли таблиць

Набір файлів для перевірки програми (ЛР1, варіант 8). Кожен файл відкривається
командою «Відкрити»; очікувані значення наведено в таблицях нижче.

Формат файлу — JSON, який створює `JsonTableStorage`: назва формату, версія,
кількість рядків і стовпчиків та вирази непорожніх клітинок (адреса → вираз).
Значення у файлі не зберігаються — після відкриття їх обчислюють заново.

## 03-dependencies.json — залежності між клітинками

- Ланцюжок A1 → A5: `A1 = 1`, `A2 = A1 + 1`, `A3 = A2 * 2`, `A4 = A3 + A2`,
  `A5 = inc(A4)`; значення 1, 2, 4, 6, 7.
- «Ромб» у стовпчику B: `B2 = B1 + 1` і `B3 = B1 * 2` залежать від B1,
  а `B4 = B2 + B3` — від обох; значення 10, 11, 20, 31. B4 перераховується
  один раз і вже після B2 та B3.
- Ланцюжок C1 → C4 записаний «знизу вгору»: `C1 = C2 + 1`, ..., `C4 = 5`;
  значення 8, 7, 6, 5 — кожна клітинка обчислюється після тих, на які посилається,
  незалежно від порядку у файлі.
- `D1 = A5 + B4 + C1` = 46, `D2 = A1 * B1` = 10.

Що перевірити вручну:

1. Змінити A1 на `10` — оновляться A2…A5 (11, 22, 33, 34), D1 = 73, D2 = 100.
2. Потім змінити B1 на `100` — B2 = 101, B3 = 200, B4 = 301, D1 = 343.
3. Ввести в A1 `A5` — програма відмовить: це циклічне посилання.

## 04-errors.json — повідомлення про помилки

| Клітинка | Вираз | Повідомлення |
|---|---|---|
| A1 | `2 + * 3` | Синтаксична помилка в позиції 5: неочікуваний символ '*' |
| A2 | `(2+3` | Синтаксична помилка в позиції 5: неочікуваний кінець виразу |
| A3 | `2 @ 3` | Синтаксична помилка в позиції 3: невідомий символ '@' |
| A4 | `10 / 0` | Ділення на нуль |
| A5 | `2 ^ -1` | Від'ємний показник степеня |
| A6 | `Z99 + 1` | Клітинка Z99 не існує |
| A7 | `A4 + 1` | Клітинка A4 містить помилку |
| A8 | `B8 + 1` | Клітинка B8 містить помилку |
| B8 | `A8` | Циклічне посилання (A8 і B8 посилаються одна на одну) |
| A9 | `1 2` | Синтаксична помилка в позиції 3: неочікуваний символ '2' (між числами немає операції) |
| B1 | `inc 5` | Синтаксична помилка в позиції 5: неочікуваний символ '5' (після inc потрібні дужки) |
| B2 | `1 + 😀` | Синтаксична помилка в позиції 5: невідомий символ '😀' |

Що перевірити вручну:

1. Змінити A4 на `10 / 2` — помилка зникне і в A7 (стане 6).
2. Ввести в A8 `5` — цикл розірвано, B8 стане 5.

## 05-broken-file.json — пошкоджений файл

Файл обрізано посередині (незакритий рядок і дужки), тому це некоректний JSON.
Програма показує повідомлення «Файл пошкоджений або має неправильний формат: …»,
а поточна таблиця залишається без змін.
